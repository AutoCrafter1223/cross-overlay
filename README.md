# CenterCross

Windows용 3D 멀미 완화 및 마우스 위치 확인 접근성 오버레이입니다. 대상 프로그램과 완전히 분리된 투명한 일반 창으로 화면 기준점, 마우스 커서 추적, 마우스 찾기 효과를 표시합니다.

> 이 프로그램은 게임 프로세스에 접근하지 않는 외부 접근성 오버레이입니다. 그러나 모든 게임이나 안티치트 시스템과의 호환성을 보장할 수 없습니다. 사용하려는 게임의 운영 정책을 확인하세요.

## 주요 기능

- 현재 활성 프로그램, 모니터 중앙 또는 특정 앱을 대상으로 선택
- 특정 앱 목록에는 아이콘과 앱 이름만 표시하고 창 제목은 저장하지 않음
- 프로그램별 프로필 자동 적용 및 현재 적용 프로필 상시 표시
- 프로필 목록에서 개별 사용 여부를 설정하고, 꺼 둔 프로필은 자동 전환과 표시에서 제외
- 특정 앱을 대상으로 선택하면 그 앱 창이 활성화된 동안에만 오버레이 표시
- 대상 클라이언트 영역 중앙을 따르는 클릭 통과 도형 오버레이
- CENTER `(0, 0)` 기준의 도형 레이어 편집기와 실시간 미리보기
- 선, 원·타원, 링, 반지름·시작 각도·호 각도를 지정하는 호, 점, 사각형, 화살표, 정삼각형, 이등변삼각형 및 PNG 조합
- 선의 둥근·각진·삼각형 끝 처리, 15~75° 삼각형 끝 경사 조절과 끝부분까지 유지되는 외곽선
- 호의 각진 끝 외곽선과 수평·수직 기준선의 둥근·각진·삼각형 끝 처리
- 좌우·상하 대칭과 각도·복사 횟수를 지정하는 원형 패턴
- 대칭 복사본과 구분되는 원본 도형 선택 표시
- PNG 원본을 바꾸지 않는 특정 색상 투명 처리(허용 범위·가장자리 부드럽게 조절)
- 화면 기준점과 동일한 다중 도형 레이어·대칭·원형 패턴·PNG 기능을 갖춘 마우스 커서 추적
- 마우스 위치를 `CURSOR (0, 0)`으로 사용하며 설정 변경 때만 캐시를 다시 생성
- 정밀 타이머 기반 자동·수동 주사율 추적과 모니터 좌표 변환 캐시
- 고정 비네팅, 가상 신체 기준점, 수평·수직 기준선, 정적 격자를 독립적으로 조합하는 멀미 완화 보조
- 멀미 완화 보조의 4개 하위 설정 화면과 게임 화면을 캡처하지 않는 16:9 예시 미리보기
- 하위 항목을 왼쪽 메뉴에 배치해 설정·미리보기 영역을 넓게 사용
- 마우스 커서 추적의 모니터 주사율 자동 감지 및 60/120/144/165/240Hz 수동 선택
- 하단 중앙 기준의 가상 코·양팔·상체 프리셋과 다중 PNG 레이어 배치
- 각 화면에서 켜 둔 기능만 함께 전환하는 전체 오버레이 단축키
- 기준선 점선 및 격자 가로·세로 점선의 길이·간격·시작 오프셋을 픽셀 단위로 설정
- 수평·수직 기준선 길이를 각각 고정 픽셀로 설정하며, 기존 여백·비율형 프로필은 자동 변환
- 정적 보조 화면은 설정 또는 해상도가 바뀔 때만 다시 생성하는 저부하 렌더링
- 각 주요 기능의 상태를 손잡이형 스위치와 왼쪽 메뉴의 색상 점으로 즉시 확인
- 바깥으로 퍼지는 선 강조와 안쪽으로 모이는 중앙 집중을 포함한 여섯 가지 마우스 찾기 애니메이션
- 보조 키가 선택 사항인 F1~F12·문자·숫자 전역 단축키와 Mouse 1~5 단축키
- 즉시 전환되는 한국어/영어 설정 화면, 시스템 트레이, 프로필 JSON 가져오기/내보내기
- 트레이에서 한국어/English 전환 및 알림 없는 명시적 완전 종료
- 모니터 배율에 맞춘 고해상도 오버레이 렌더링과 화면 맞춤·25/50/75/100% 미리보기, 100%에서 가로·세로 스크롤
- 일반 창 모드와 테두리 없는 전체 화면에서 오버레이 최상위 유지
- 사용자 영역 `%LOCALAPPDATA%\CenterCross\settings.json`에 원자적으로 설정 저장
- 간결한 상단 적용 상태 표시와 일반 화면의 프로필별 대상·오버레이 적용 현황
- 적용 현황에서 저장된 기능 설정과 현재 화면 표시 상태를 구분
- 작은 창에서는 설정·미리보기를 탭으로 전환하며 한국어/영어 화면을 자동 재배치
- Ctrl+Z 실행 취소와 미리보기 방향키 이동(1 px, Shift 10 px), 미리보기 하단의 24 px 격자 맞춤 및 중심 정렬
- 도형 종류에 필요한 속성만 표시하며 대칭·패턴 설정은 펼쳐서 편집
- 드래그를 한 번의 실행 취소 단위로 처리하고 설정 저장을 지연해 편집 중 저장 부담 완화
- 화면 가장자리에서 안쪽으로 뻗는 가로선·세로선 각각의 길이를 고정 픽셀 값으로 조절
- PNG를 앱 이미지 폴더에 복사해 보관하며 프로필·도형·커서 프리셋 JSON에 이미지도 포함해 공유
- 손상된 설정을 `settings.corrupt-날짜.json`으로 백업한 뒤 기본값 복구

## 실행

요구 사항은 Windows 10/11, Python 3.12입니다. 관리자 권한은 필요하지 않습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.pyw
```

**일반** 화면에서 대상 프로그램을 현재 활성 프로그램, 모니터 중앙 또는 특정 앱으로 선택하세요. 특정 앱 목록에는 개인정보가 포함될 수 있는 창 제목 대신 앱 아이콘과 이름만 표시됩니다. 등록되는 기본 단축키는 `Alt+Q`(찾기 효과)과 `Ctrl+Alt+R`(전체 오버레이)이며 UI의 목록에서 변경할 수 있습니다.

## 테스트

핵심 설정/좌표 테스트는 추가 패키지 없이 실행할 수 있습니다.

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

전체 개발 도구 설치 후에는 `pytest`도 사용할 수 있습니다.

## 실행 파일 빌드

```powershell
python -m pip install -r requirements-dev.txt
pyinstaller --clean --noconfirm CenterCross.spec
```

결과는 `dist\CenterCross.exe`입니다. 설치 프로그램이나 드라이버는 만들지 않으며 사용자 권한으로 실행됩니다.

## 의존성

- **PySide6**: Qt 기반 한국어 설정 화면, 투명 최상위 창, 트레이 및 저부하 타이머에 사용합니다.
- 개발 전용 **pytest**: 선택적 테스트 실행기입니다.
- 개발 전용 **PyInstaller**: 단일 Windows 실행 파일 패키징에 사용합니다.

그 외 Windows 기능은 Python 표준 라이브러리 `ctypes`와 `winreg`만 사용합니다.

## 알려진 제한사항

- 독점 전체 화면은 Windows가 외부 최상위 창을 게임 위에 합성하지 않을 수 있어 지원을 보장하지 않습니다. 창 모드와 테두리 없는 전체 화면을 권장합니다.
- 일부 게임 또는 안티치트 정책은 외부 오버레이 자체를 금지할 수 있습니다. 사용 전 운영 정책을 확인하세요.
- 같은 앱의 창이 여러 개이면 현재 활성화된 창을 우선 사용하고, 활성 창이 없으면 첫 번째 일반 창을 사용합니다.
- 단축키를 다른 프로그램이 이미 등록했다면 다른 조합을 지정해야 합니다.
- 서로 다른 DPI의 모니터는 Per-Monitor DPI Awareness v2와 물리 화면 좌표를 사용하지만, 실제 복합 모니터 환경별 확인을 권장합니다.

자세한 안전 경계와 검증 범위는 [SAFETY.md](SAFETY.md)를 참고하세요. 향후 화면 분석 기반 기능은 현재 정적 오버레이와 분리된 [EXTENSION_PLAN.md](EXTENSION_PLAN.md)의 확장 원칙을 따릅니다.
